# FastAPI Inference Service

Base URL (local): `http://localhost:8000`

Start the service:

```bash
uv run python main.py run-api
# or
uv run uvicorn object_tracking_app.deployment.api:app --app-dir src --host 0.0.0.0 --port 8000
```

Interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI) and
`/redoc`.

## `GET /health`

Health check.

**Response**
```json
{ "status": "ok", "version": "0.1.0" }
```

## `GET /classes`

Returns the class-index → class-name mapping of the currently loaded model.

**Response**
```json
{ "classes": { "0": "person", "1": "car", "2": "bicycle", "...": "..." } }
```

## `POST /predict`

Run detection on an uploaded image.

**Form data**
| Field | Type | Required | Description |
|-------|------|----------|--------------|
| `file` | file | yes | Image file (jpg/png/bmp) |

**Query params**
| Param | Type | Default | Description |
|-------|------|---------|--------------|
| `conf_threshold` | float | from `configs/inference.yaml` | Minimum confidence to keep a detection |
| `iou_threshold` | float | from `configs/inference.yaml` | NMS IOU threshold |
| `return_image` | bool | `false` | If `true`, returns an annotated JPEG instead of JSON |

**Example**
```bash
curl -X POST "http://localhost:8000/predict?conf_threshold=0.4" \
  -F "file=@data/samples/example.jpg"
```

**JSON response**
```json
{
  "num_detections": 3,
  "class_counts": { "person": 2, "car": 1 },
  "mean_confidence": 0.71,
  "detections": [
    {
      "box_xyxy": [120.4, 88.1, 340.7, 410.9],
      "confidence": 0.91,
      "class_id": 0,
      "class_name": "person"
    }
  ]
}
```

**Annotated image response** (`return_image=true`): raw `image/jpeg` bytes
with bounding boxes and labels drawn.

**Errors**
| Status | Cause |
|--------|-------|
| `400` | Uploaded file could not be decoded as an image |
| `413` | Uploaded file exceeds `deploy.yaml → api.max_upload_size_mb` |
| `500` | Inference failed (see server logs) |

## Notes

- The API currently performs **detection only** (no tracking), since
  tracking is inherently a multi-frame/stateful operation. For tracking,
  use `POST /predict` on successive frames from your own client, or use the
  video/webcam pipelines directly via `main.py infer-video` /
  `main.py infer-webcam`, or the Streamlit **Video Inference** page.
- CORS is configured via `configs/deploy.yaml → api.cors_allow_origins`
  (defaults to `["*"]` for local development -- tighten this before any
  production deployment).
